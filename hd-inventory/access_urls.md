# Guía de Acceso — HD Inventory

Este documento contiene los enlaces y credenciales necesarios para acceder a las distintas partes del sistema de inventario en el entorno local.

| Servicio | URL | Descripción |
| :--- | :--- | :--- |
| **Frontend (React)** | [http://localhost:5173](http://localhost:5173) | Interfaz de usuario (Login, Dashboard, Despacho, etc.) |
| **Backend (API)** | [http://localhost:8000/api/](http://localhost:8000/api/) | Punto de entrada de la API REST para desarrollo |
| **Django Admin** | [http://localhost:8000/admin/](http://localhost:8000/admin/) | Panel de administración de base de datos y usuarios |

## Credenciales de Acceso (Admin)

Para las pruebas iniciales, puedes utilizar la siguiente cuenta con privilegios de **Manager**:

- **Usuario:** `admin`
- **Contraseña:** `Admin2026!`

---

> [!TIP]
> Asegúrate de que los contenedores de Docker estén corriendo (`docker compose up -d`) antes de intentar acceder a estos enlaces.
